# Growth & Moat

Skills for the stage where the motion repeats and you scale, instrument, and defend it.

| Skill | What it does | Status |
|---|---|---|
| [`compound-growth-check`](./compound-growth-check) | Takes 6+ quarters of ARR, classifies the trajectory (compounding / inflection / decompounding / decay), and places you on the 10-state growth ladder. Includes a self-contained Python script | Available |
| [`ai-use-case-gate`](./ai-use-case-gate) | Gates any proposed AI build for a GTM team: constraint check first, then the ship gate, then placement on the capability ladder with guardrails | Available |
| [`epistemic-context-grounding`](./epistemic-context-grounding) | Grounds implementation decisions in domain knowledge before designing solutions: check what exists, make assumptions explicit, verify against sources. By Jacob Dietle (see NOTICE) | Available |
| [`context-gap-analysis`](./context-gap-analysis) | Enumerates required context, checks what exists, and finds the simplest path forward before any task. By Jacob Dietle (see NOTICE) | Available |
